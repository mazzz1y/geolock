# GeoLock v2 config schema

The current schema, shipped from GeoLock 2.0.0.

## Top-level shape

```json
{
  "version": 2,
  "default_action": "allow",
  "data_sources": {
    "geoip":   { "url": "", "auto_update": true, "interval_hours": 24, "sha256_url": "" },
    "geosite": { "url": "", "auto_update": true, "interval_hours": 24, "sha256_url": "" }
  },
  "dns": {
    "cache_ttl_seconds": 300,
    "negative_cache_ttl_seconds": 30,
    "timeout_ms": 5000,
    "match_strategy": "first"
  },
  "rules": []
}
```

| Field | Type | Notes |
|---|---|---|
| `version` | `2` | Required. |
| `default_action` | `"allow"` \| `"block"` | Outcome when no rule fires. |
| `data_sources.geoip.url` | https URL or empty | v2fly geoip.dat source. |
| `data_sources.geoip.auto_update` | boolean | When true, periodic updates fetch the URL. |
| `data_sources.geoip.interval_hours` | positive number | Update interval. |
| `data_sources.geoip.sha256_url` | https URL or empty | Optional companion SHA-256 manifest URL. |
| `data_sources.geosite.*` | same as geoip | v2fly geosite.dat source. |
| `dns.cache_ttl_seconds` | integer 0..86400 | Positive DNS cache TTL. |
| `dns.negative_cache_ttl_seconds` | integer 0..3600 | Negative DNS cache TTL. |
| `dns.timeout_ms` | integer 50..30000 | Per-lookup timeout. |
| `dns.match_strategy` | `"first"` \| `"all"` | Whether to evaluate the first resolved IP only or all of them. |
| `rules` | array of rules | Evaluated in order; first match wins. |

## Rule shape

### Flow rule (default)

```json
{
  "name": "",
  "enabled": true,
  "action": "block",
  "strip_referrer": false,
  "bidirectional": false,
  "source":      { "type": "any" },
  "destination": { "type": "any" }
}
```

| Field | Type | Notes |
|---|---|---|
| `name` | string | Display label. |
| `enabled` | boolean | Disabled rules are skipped. |
| `action` | `"allow"` \| `"block"` | Outcome when the rule fires. |
| `strip_referrer` | boolean | When `action: "block"`, strips the Referer header on top-level navigation instead of cancelling. Requires `action: "block"`. |
| `bidirectional` | boolean | When true, the rule also fires when source and destination roles are swapped. |
| `source` | matcher | Matches the page making the request. |
| `destination` | matcher | Matches what the page is loading. |

### Isolate rule

```json
{
  "name": "no cross-US traffic",
  "enabled": true,
  "mode": "isolate",
  "action": "block",
  "strip_referrer": false,
  "match": { "type": "geoip", "tag": "us" }
}
```

| Field | Type | Notes |
|---|---|---|
| `mode` | `"isolate"` | Discriminator. Omit for flow rules. |
| `match` | matcher | Single matcher defining the boundary. |

Isolate rules fire when exactly one of source or destination is in the match set. Internally desugared to a bidirectional flow rule with `source = match` and `destination = NOT match`.

Isolate rules reject `source`, `destination`, and `bidirectional` as unknown fields.

## Matcher shape

Every matcher has a `type` discriminator.

| `type` | Body fields | Meaning |
|---|---|---|
| `any` | — | Always matches. |
| `geosite` | `tag` (non-empty string), `attr` (string, optional) | Matches a v2fly geosite category, optionally scoped to an attribute (e.g. `google@ads`). |
| `geoip` | `tag` (non-empty string) | Matches the resolved IP country. |
| `domain` | `regex` (non-empty string, valid RegExp) | Matches the hostname. |
| `url` | `regex` (non-empty string, valid RegExp) | Matches the full URL. |
| `ip` | `cidr` (valid IPv4/IPv6 CIDR) | Matches the resolved IP. |
| `and` | `matches` (non-empty array of matchers) | Logical AND. |
| `or` | `matches` (non-empty array of matchers) | Logical OR. |
| `not` | `match` (matcher) | Logical NOT. |

## Example

```json
{
  "version": 2,
  "default_action": "allow",
  "data_sources": {
    "geoip":   { "url": "https://example.com/geoip.dat",   "auto_update": true, "interval_hours": 24, "sha256_url": "" },
    "geosite": { "url": "https://example.com/geosite.dat", "auto_update": true, "interval_hours": 24, "sha256_url": "" }
  },
  "dns": { "cache_ttl_seconds": 300, "negative_cache_ttl_seconds": 30, "timeout_ms": 5000, "match_strategy": "first" },
  "rules": [
    {
      "name": "block ads on banking sites",
      "enabled": true,
      "action": "block",
      "strip_referrer": false,
      "bidirectional": false,
      "source":      { "type": "domain", "regex": "(^|\\.)mybank\\.example$" },
      "destination": { "type": "geosite", "tag": "category-ads-all" }
    },
    {
      "name": "no cross-US traffic",
      "enabled": true,
      "mode": "isolate",
      "action": "block",
      "match": { "type": "geoip", "tag": "us" }
    }
  ]
}
```
